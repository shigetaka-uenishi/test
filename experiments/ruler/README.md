# 定規実験（#8）

正解の位置が分かっている人工画像（白地に ID 付きの四角）で、モデルの座標の答え方を測る。
#2 の座標ずれが「座標の形式（0〜1000 の正規化）」によるものか、「レイアウトの複雑さ」によるものかを切り分けるのが目的。

## 条件

| | 正規化（0〜1000） | ピクセル |
|---|---|---|
| `tall`（1419×2000、漫画と同じ。24 個） | ○ | ○ |
| `square`（1685×1685、同じ画素数。25 個） | ○ | ○ |

正規化の指示文は `manga_analyzer` の `SYSTEM_PROMPT` と同じ言い方にそろえている。

## 手順

```bash
# 1. 画像と正解を作る（API なし。シード固定なので毎回同じ画像になる）
python experiments/ruler/ruler.py make

# 2. API 環境で実行する（4 条件 × 3 回 = 12 回呼び出す）
python experiments/ruler/ruler.py run --runs 3
#    → results/<画像>__<形式>__r<回>.json ができるので、コミットしてプッシュする
#    すでにある結果は飛ばすので、途中で止まってもそのまま再実行できる

# 3. 採点する（API なし）
python experiments/ruler/ruler.py score --draw
#    → 表（Markdown）を出力。out/overlays/ に正解（緑）と答え（赤）の重ね描き
```

## 表の見方

軸ごとに「答え = a × 正解 + b」（px）を当てはめている。

- `a_x` / `a_y`: 倍率。1 からずれる → 換算の問題（例: 1.05 なら下・右ほど大きくずれる）
- `b_x` / `b_y`: 平行移動（px）。0 でない → 全体が一方向にずれる
- `rms_x` / `rms_y`: 直線で説明できない残りのばらつき（px）→ 見る力の限界
- `mean_abs_err`: 辺の位置の平均誤差（px）
- `iou`: 正解との重なり率の平均（1 が完全一致）
- `missing` / `extra`: 見逃した四角の数／存在しない ID を答えた数

複数回実行した条件は「平均 ± 標準偏差」で出る。
